### 👨‍💻 About Me

Saya seorang **Software Developer** yang berfokus pada pengembangan aplikasi web *end-to-end*, mulai dari perancangan database hingga antarmuka pengguna yang responsif. Saat ini aktif mengembangkan dan memelihara **Sistem Informasi Manajemen Rumah Sakit (SIMRS)** serta berbagai solusi perangkat lunak berbasis web.

- 🔭 **Fokus saat ini:** Pengembangan sistem informasi kesehatan (SIMRS) & optimasi aplikasi web skala enterprise.
- 🌱 **Sedang mendalami:** Ekosistem **TALL Stack** (*Tailwind, Alpine.js, Laravel, Livewire*), **Filament**, & arsitektur **React**.
- ⚡ **Fun fact:** Suka ngulik *custom workflow* di terminal dan eksplorasi berbagai *AI coding agents*.
